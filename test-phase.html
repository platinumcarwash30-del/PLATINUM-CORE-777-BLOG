01WHAT THIS IS

A controlled test version, built for responsible feedback.

CORE REVIEW is not presented as a finished mass-market product. It is being tested in a controlled way so that account creation, owner approval, roles, verified visits, reviews, notifications and communication can be checked before wider release.

01 / USERSOne account per person.

Profiles and access are connected to a real user and reviewed through controlled roles.

02 / TRUSTApproval before wider access.

Testing is designed around responsible access, clear roles and reviewable activity.

03 / FEEDBACKEvery test matters.

Feedback helps identify what must be corrected before a broader release.

02HOW ACCESS WORKS

From support to controlled testing.

  1. 01 — Contact the project.
    Tell us that you are interested in the CORE REVIEW test phase.
  2. 02 — Support according to your possibilities.
    Support helps development, testing, infrastructure, documentation and professional presentation.
  3. 03 — Receive instructions when access is available.
    Selected testers may receive an access code and installation instructions.
  4. 04 — Use the test version responsibly.
    Report problems honestly and do not share access codes or private information publicly.
For access, questions, sponsorship or partnership, contact markoplatinum@icloud.com.

03PRIVACY & DATA

Privacy is part of the test.

CORE REVIEW may process account and profile details, approval information, verified visit information, reviews, notes and notifications needed to provide the service. Access is limited by role and purpose. Personal data is not sold for advertising.

Read the complete CORE REVIEW Privacy Policy for data use, sharing, security, retention and deletion information.

04ACCOUNT DELETION

Users can request account deletion.

Users can request deletion from the app where the option is available. An external request can also be sent by email with the subject “CORE REVIEW Account Deletion”. Please include the account email so the correct account can be identified.
